## 3. 当前架构（口径统一版，勿另起炉灶）

**主路径 = SearchTreeRunner**（`search_tree.py`）：
问题 → 查询净化（剥问句壳）→ DeepSeek 规划（失败退规则）→ arXiv+OpenAlex
检索（RRF 跨源融合）→ 每层新增论文 LLM 判断（无判断退词法分）→ 引用扩展
（`expand_mode`：默认 `openalex`=拉参考文献列表；`hybrid`=读正文点名优先，
当前有缺陷见 P1-4）→ 垃圾池换词重搜 → 双预算硬顶（provider/LLM）→ 出池。

**交付物 = spar.final.v2**（`final_output.py`）：
- `results`：按 `select_threshold=0.55` 选出的**提交集合**（上限 30），
  对应官方 document-level P/R/F1；
- `ranked_pool`：按分数排序的前 50 篇（含未判分者垫底），对应官方
  Recall@20/50/100；
- `selection_rule`：选择规则落盘可审计。

**评测 = pasa_metrics.py（官方口径，主指标）**：keep_letters 标题匹配
（只留字母小写）、宏观平均、recall@20/50/100、crawler_recall、selected
P/R/F1。`p2_metrics.py` 的 F1@10 是更严的参考口径。
注意：keep_letters 会剥数字（"Part 2"/"GPT-4" 型标题可能撞车），对标 PaSa
无妨，对官方未知规则交卷时不要依赖标题匹配结论。

**已建成资产**（测试覆盖、直接复用）：PaperDoc 协议+身份互认
（arXiv-DOI↔arXiv-ID）、错误纪律（空≠失败、LLM 失败≠0 分）、成本计量
框架（P2 管线路径完整；tree 路径 token 缺，见 P0-2）、本地全文抽取层
（`fulltext.py`，纯本地 pymupdf 无需 API）、正文流程组件
（`fulltext_flow.py`：章节挑选/引用点名/双评审——**仅试点脚本使用，未入
主路径**）、spar.final.v2 交付物。

| 指标（官方口径） | 数值 |

## 5. 老师审计结论（已由前任逐项核验为真，全部成立）

1. **P0-1 实锤 bug**：最后一层引用扩展入池的论文永远得不到判分
   （relevance=None 沉底）。50 题里 1,287 篇僵尸论文、其中 4 篇 Gold
   （test_4×1、test_8×2、test_20×1——池内召回满但 top-20 全零）。
   模拟修复后 recall@20 0.298→**0.328（+3pp，全项目最便宜的收益）**。
2. **P0-2**：tree 路径 token 从未落盘（`autoscholar_pipeline_eval.py:91`
   硬编码 `total_tokens: None`），效率分（20%）处于盲区。
3. 双评审（dual_review）与融合打分（blend_relevance）**不在主路径**，
   对 0.298 贡献为零——此前"已验证可用"的说法只对试点脚本成立。
4. hybrid 正文点名当前是安慰剂：`search_tree.py` 的 `_expand_via_fulltext`
   里标题匹配要求归一化后**完全相等**，过于苛刻，点名成功也常查不回；
   且 arXiv HTML 无缓存导致单题 2.5-6 分钟超红线。
5. 创新点定位（答辩口径）：**可审计检索协议层**（PaperDoc/身份互认/错误
   纪律/成本回放，244 测试）+ **判分预算调度**（P0-1 即第一个实例）。
   双 Agent 互评现状站不住（同模型换 persona≈self-consistency），要么升级
   成信息不对称互评并出 P-R 曲线，要么删。

## 7. 5 题哨兵制度（唯一合法的联网验证方式）

- **固定哨兵集，不随机**。已定（scripts_sentinel_5.py 硬编码）：
  test_4、test_8（排序失败×2，盯 P0-1）、test_0（零召回+错领域，防伤召回）、
  test_3（最高分段 0.60，防回退）、test_20（部分分+排序敏感，判分校准探针）。
- 每轮验证流程：改代码 → 全量单测 → 哨兵 5 题（跑前报成本）→ 与
  `artifacts/autoscholar/tree-n50-v2*/<qid>/papers.json` 同题配对 →
  出胜负表（哪些题变好/变坏/不变）→ 提交 + 简报。
- 简报口径：官方指标（recall@20/50、selected_f1）+ 效率（API/token/分钟）
  + 与基线的同题胜负表。**不报未接入主路径机制的效果。**
- 单题单次波动极大（LLM 非确定性），哨兵结论模糊时可跑第二遍取均值，
  仍模糊则回滚改动而不是加题。
